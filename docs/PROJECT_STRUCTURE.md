# Project Structure

```text
webgis-main/
├── index.html
├── style.css
├── script.js
├── package.json
├── README.md
├── docs/
│   ├── DEVELOPMENT.md
│   └── PROJECT_STRUCTURE.md
└── .vscode/
    ├── extensions.json
    └── settings.json
```

## Root Files

- `index.html` — entry point aplikasi.
- `style.css` — style utama aplikasi.
- `script.js` — logic utama aplikasi WebGIS.
- `package.json` — helper script untuk development lokal.
- `README.md` — dokumentasi utama untuk GitHub.

## Folder `docs/`

Berisi dokumentasi tambahan untuk developer.

## Folder `.vscode/`

Berisi rekomendasi editor agar pengalaman development lebih konsisten.
